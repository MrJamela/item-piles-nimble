# Item Piles: Nimble

Adds Nimble system support to the Item Piles module for Foundry VTT (v14): loot piles, merchants, trading and coins.

Needs: the Nimble system and Item Piles (3.3 or newer).

## What it sets up
- Coins: Gold, Silver and Copper from the character sheet (1 gp = 10 sp = 100 cp).
- Items: Nimble objects, with their quantity and price (a price in silver or copper is read as such).
- Hidden from piles: class, subclass, ancestry, background, boons, features and spells.
- Piles and merchants are Nimble characters (the only actors that carry coins), with a neutral token and no sight.
- An object that changes hands arrives unequipped and out of any bag.
